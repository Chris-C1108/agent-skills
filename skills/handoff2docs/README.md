# handoff2docs

> 将当前 Agent 会话提炼为结构化交接文档与避坑经验教训，落盘至 `docs/handoff/`。

## 核心功能
- 生成会话交接快照：`docs/handoff/YYYY-MM-DD-HHmmss-handoff.md`
- 记录故障避坑教训：`docs/handoff/YYYY-MM-DD-HHmmss-lesson.md`
- 自动维护全局索引总账：`docs/handoff/handoff-readme.md`

## 触发词
- `handoff2docs` / `/handoff2docs`
- `handoff` / `/handoff`
- 会话交接 / 归档经验教训
